## О проекте

Это **персональный сайт-портфолио** на базе **Quartz 4** — статического генератора сайтов, который преобразует заметки Obsidian (Markdown файлы) в полноценный веб-сайт.

### Технический стек:
- **Генератор:** Quartz 4.5.0
- **Язык:** TypeScript/JavaScript
- **Управление пакетами:** npm
- **Хостинг:** GitHub Pages
- **Автоматическая публикация:** GitHub Actions
- **URL сайта:** https://parkpavel.github.io/park-pavel/

### Основные возможности:
- ✅ Поддержка русского языка
- ✅ Светлая и тёмная темы
- ✅ Интерактивный граф связей
- ✅ Полнотекстовый поиск
- ✅ Google Analytics интеграция
- ✅ Кастомные компоненты (профиль, обложка, карусель)
- ✅ Автоматическое создание OG-изображений

## Базовые принципы безопасности

### 🛡️ Золотые правила работы через агента:

1. **Всегда делай резервную копию** перед серьёзными изменениями
   ```bash
   git status              # Проверить текущее состояние
   git diff                # Посмотреть незакоммиченные изменения
   git log --oneline -5    # Последние коммиты
   ```

2. **Минимальные изменения** — не трогай то, что работает
   - Изменяй только файлы, связанные с твоей задачей
   - Не переписывай код полностью, если можно внести точечное изменение
   - Не обновляй зависимости без необходимости

3. **Тестируй локально перед коммитом**
   ```bash
   npm ci                  # Установить зависимости
   npx quartz build        # Собрать сайт
   npx quartz serve        # Запустить локальный сервер
   ```

4. **Коммиты с осмысленными сообщениями**
   ```bash
   git add content/новая-страница.md
   git commit -m "docs: добавлена страница о новом курсе массажа"
   git push
   ```

5. **Используй ветки для экспериментов**
   ```bash
   git checkout -b feature/new-gallery
   # вносим изменения
   git add .
   git commit -m "feat: добавлена новая галерея"
   git push -u origin feature/new-gallery
   ```

6. **Не удаляй без понимания**
   - Файлы в `quartz/` — это движок, не трогай без крайней необходимости
   - Файлы в `content/` — твой контент, можно редактировать смело
   - Конфигурации (`.config.ts`, `.layout.ts`) — изменяй аккуратно

## Типовые задачи и команды

### 📝 Задача 1: Добавить новую страницу

**Контекст для агента:**
```
Мне нужно добавить новую страницу в раздел "Массаж". 
Название: "Стоун-терапия"
Содержание: [описываешь контент]

ВАЖНО: 
- Используй формат Markdown
- Добавь frontmatter с title и description
- Сохрани в папку content/Массаж и СПА-ритуалы/
- Проверь ссылки на эту страницу
```

**Команды для агента:**
```bash
# 1. Создать файл
cat > "content/Массаж и СПА-ритуалы/Стоун-терапия.md" << 'EOF'
---
title: Стоун-терапия
description: Массаж горячими камнями для глубокого расслабления
---

# Стоун-терапия

[Твой контент здесь]
EOF

# 2. Проверить синтаксис
npx quartz build

# 3. Закоммитить
git add "content/Массаж и СПА-ритуалы/Стоун-терапия.md"
git commit -m "docs: добавлена страница о стоун-терапии"
git push
```

### 🎨 Задача 2: Изменить цветовую схему

**Контекст для агента:**
```
Хочу изменить основной акцентный цвет в светлой теме.
Текущий: #687864 (sage green)
Новый: #5A7A5A (darker sage)

Файл: quartz.config.ts
Секция: theme.colors.lightMode.secondary

ВАЖНО: Не трогай другие цвета, только secondary
```

**Проверка после изменения:**
```bash
npx quartz build
npx quartz serve
# Открой http://localhost:8080 и проверь цвета
```

## Работа с контентом

### Структура Markdown файлов

Каждый файл должен иметь **frontmatter** (метаданные) и **контент**:

```markdown
---
title: Название страницы
description: Краткое описание для SEO
tags:
  - йога
  - практика
date: 2024-12-02
---

# Заголовок страницы

Твой контент в Markdown формате.

## Подзаголовок

- Списки
- Ссылки: [[Другая страница]]
- Изображения: ![alt](url)

### Подподзаголовок

**Жирный текст**, *курсив*, `код`
```

### Obsidian-стиль ссылок

Quartz поддерживает ссылки в стиле Obsidian:

```markdown
[[Название страницы]]              # Простая ссылка
[[Название страницы|Текст ссылки]] # Ссылка с кастомным текстом
![[Изображение.png]]               # Встроенное изображение
```

### Специальные возможности

```markdown
# Математика (LaTeX)
$$
E = mc^2
$$

# Код с подсветкой
```python
def hello():
    print("Привет!")
```

# Выноски/Callouts
> [!note] Заметка
> Важная информация

> [!warning] Предупреждение
> Будь осторожен!
```

## Кастомные компоненты

Твой сайт использует несколько **уникальных компонентов**, которые важно понимать:

### 1. **ProfilePhoto** — Фото профиля

**Файл:** `quartz/components/ProfilePhoto.tsx`

**Что делает:** Отображает круглое фото профиля на главной странице

**Изображение:** `quartz/static/profilePhoto.png`

**Стиль:** 150x150px, скругленные углы, увеличение при наведении

**Где используется:** Только на главной странице (index.md)

**Как обновить фото:**
1. Подготовь новое изображение 150x150px
2. Сохрани в `quartz/static/profilePhoto.png`
3. Собери проект: `npx quartz build`

### 2. **HomepageCover** — Обложка главной страницы

**Файл:** `quartz/components/HomepageCover.tsx`

**Что делает:** Показывает большую обложку с адаптацией под светлую/тёмную тему

**Изображения:**
- Светлая тема: `quartz/static/og-imagelight.png`
- Тёмная тема: `quartz/static/og-imagedark.png`

**Где используется:** Только на главной странице

**Как обновить обложку:**
1. Создай два варианта изображения (light/dark)
2. Оптимизируй размер (рекомендуется < 500KB каждый)
3. Замени файлы в `quartz/static/`
4. Собери: `npx quartz build`

### 3. **Carousel** — Галерея изображений

**Файл:** `quartz/components/Carousel.tsx`

**Что делает:** 
- Отображает горизонтальную карусель фотогалерей
- Позволяет переключаться между альбомами
- Открывает модальное окно для просмотра в полный размер
- Навигация стрелками внутри модального окна

**Как использовать:**

В frontmatter страницы добавь:
```yaml
---
title: Моё портфолио
portfolioGalleries:
  - title: "Альбом 1"
    urls:
      - "https://url-to-image1.jpg"
      - "https://url-to-image2.jpg"
  - title: "Альбом 2"
    urls:
      - "https://url-to-image3.jpg"
---
```

**Управление:**
- Кнопки < > для переключения альбомов
- Клик на фото → открытие в модальном окне
- В модальном окне: стрелки < > для навигации между фото
- Кнопка × для закрытия модального окна

### 4. **Flex** — Гибкий контейнер

**Файл:** `quartz/components/Flex.tsx`

**Что делает:** Позволяет располагать компоненты рядом (flexbox)

**Где используется:** На главной странице для размещения фото профиля рядом с заголовком

**Пример конфигурации в quartz.layout.ts:**
```typescript
Component.Flex({
  components: [
    { Component: ProfilePhoto(), basis: "150px" },
    { Component: Component.ArticleTitle(), grow: true },
  ],
})
```

### 5. **ConditionalRender** — Условный рендеринг

**Файл:** `quartz/components/ConditionalRender.tsx`

**Что делает:** Показывает компонент только при выполнении условия

**Где используется:** 
- Показ обложки только на главной
- Показ flex-контейнера с фото только на главной

**Пример:**
```typescript
Component.ConditionalRender({
  component: Component.HomepageCover(),
  condition: (page) => page.fileData.slug === "index",
})
```

## Что НЕЛЬЗЯ трогать

### 🚫 Критические файлы и папки:

1. **`quartz/` (кроме `quartz/static/` и кастомных компонентов)**
   - Это ядро Quartz, не модифицируй без глубокого понимания
   - Обновления Quartz идут через git merge, не через ручное редактирование

2. **`node_modules/`**
   - Генерируется автоматически
   - Не коммитится в git
   - Не редактируй вручную

3. **`public/`**
   - Результат сборки, генерируется автоматически
   - Удаляется и пересоздаётся при каждой сборке

4. **`.github/workflows/deploy.yml`** (без понимания CI/CD)
   - Это скрипт автоматического деплоя
   - Изменения могут сломать публикацию сайта

5. **`package-lock.json`**
   - Автоматически управляется npm
   - Не редактируй вручную, только через npm install/update

### ⚠️ Осторожно с изменениями:

1. **`quartz.config.ts`**
   - Изменения могут сломать плагины или темы
   - Тестируй после каждого изменения

2. **`quartz.layout.ts`**
   - Управляет расположением всех компонентов
   - Ошибки могут сломать весь макет

3. **`package.json`**
   - Обновление версий зависимостей может сломать совместимость
   - Всегда тестируй после изменения зависимостей

### ✅ Безопасно редактировать:

1. **Вся папка `content/`** — твой контент, редактируй свободно
2. **`quartz/static/`** — изображения и статические файлы
3. **Кастомные компоненты** (если понимаешь TypeScript):
   - `quartz/components/ProfilePhoto.tsx`
   - `quartz/components/HomepageCover.tsx`
   - `quartz/components/Carousel.tsx`
   - `quartz/components/Flex.tsx`
   - `quartz/components/ConditionalRender.tsx`

## Troubleshooting

### Проблема: Сайт не собирается (npx quartz build)

**Возможные причины:**
1. Ошибки в Markdown синтаксисе
2. Проблемы с зависимостями
3. Ошибки в конфигурации

**Решение:**
```bash
# 1. Проверь последние изменения
git diff

# 2. Посмотри лог ошибок внимательно
npx quartz build 2>&1 | tee build.log

# 3. Откат последних изменений (если нужно)
git checkout -- файл_с_ошибкой

# 4. Переустанови зависимости
rm -rf node_modules package-lock.json
npm install

# 5. Попробуй собрать снова
npx quartz build
```

### Проблема: Изменения не отображаются на сайте

**Возможные причины:**
1. Изменения не закоммичены
2. GitHub Actions не запустился
3. Кэш браузера

**Решение:**
```bash
# 1. Проверь статус git
git status

# 2. Закоммить и запушить
git add .
git commit -m "твоё сообщение"
git push

# 3. Проверь статус GitHub Actions
# Зайди на https://github.com/ParkPavel/park-pavel/actions

# 4. Очисти кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)
```

### Проблема: Кастомный компонент не работает

**Проверь:**
1. Синтаксис TypeScript/JSX
2. Импорты компонента в `quartz/components/index.ts`
3. Использование компонента в `quartz.layout.ts`

**Отладка:**
```bash
# Проверка TypeScript ошибок
npx tsc --noEmit

# Сборка с подробными логами
npx quartz build --verbose
```

### Проблема: CustomOgImages plugin ошибка (fetch failed)

2. Посмотри на ошибки внимательно
3. Используй секцию Troubleshooting
4. Спроси агента о конкретной ошибке, предоставив контекст
