# Шаблоны для создания новых страниц

Используй эти шаблоны при создании нового контента.

## Базовый шаблон страницы

```markdown
---
title: Название страницы
description: Краткое описание для SEO (1-2 предложения)
tags:
  - тег1
  - тег2
date: 2024-12-02
---

# Название страницы

Краткое вступление (1-2 абзаца).

## Основной раздел

Твой контент здесь.

### Подраздел

Детали...

## Дополнительная информация

Заключительная часть.

---

## Связанные страницы

- [[Другая страница]]
- [[Ещё одна страница]]
```

## Шаблон индексной страницы раздела

```markdown
---
title: Название раздела
description: Обзор раздела
---

# Название раздела

Краткое описание раздела (2-3 предложения).

## Содержание раздела

- [[Подраздел 1]] — краткое описание
- [[Подраздел 2]] — краткое описание
- [[Подраздел 3]] — краткое описание

## О разделе

Более подробная информация о том, что можно найти в этом разделе.

---

[[index|← Вернуться на главную]]
```

## Frontmatter параметры

Основные параметры для frontmatter:

```yaml
title: "Название страницы"           # Обязательный
description: "Описание для SEO"      # Рекомендуется
tags:                                # Опционально
  - тег1
  - тег2
date: 2024-12-02                    # Опционально (дата создания)
draft: false                         # Опционально (черновик или нет)
author: "Пак Павел"                 # Опционально
aliases:                             # Опционально (альтернативные названия)
  - "Другое название"
  - "Ещё название"

# Для портфолио с галереей:
portfolioGalleries:                  # Опционально
  - title: "Альбом"
    urls:
      - "url1"
      - "url2"

# Для услуг:
price: "1000 руб."                  # Опционально
duration: "45 минут"                # Опционально
```

## Советы по созданию контента

### Заголовки
- `#` — Главный заголовок (H1) — один на страницу
- `##` — Разделы (H2)
- `###` — Подразделы (H3)
- Не перескакивай уровни (H1 → H3)

### Ссылки
- Внутренние: `[[Название страницы]]`
- С текстом: `[[Страница|Текст ссылки]]`
- Внешние: `[Текст](https://url)`

### Списки
```markdown
# Маркированный
- Пункт 1
- Пункт 2
  - Вложенный пункт

# Нумерованный
1. Первый
2. Второй
3. Третий
```

### Выделение
```markdown
**Жирный текст**
*Курсив*
***Жирный курсив***
`Код`
~~Зачёркнутый~~
```

### Callouts (выноски)
```markdown
> [!note] Заметка
> Полезная информация

> [!warning] Внимание
> Важное предупреждение

> [!tip] Совет
> Рекомендация

> [!info] Информация
> Дополнительные сведения
```

### Изображения
```markdown
# Внешнее изображение
![Описание](https://url-to-image.jpg)

# Локальное (в static)
![Описание](/static/image.png)

# Obsidian-стиль
![[image.png]]
```


### Код



## Быстрый старт

1. Скопируй нужный шаблон
2. Заполни frontmatter
3. Напиши контент
4. Сохрани в нужную папку `content/`
5. Собери проект: `npx quartz build`
6. Проверь: `npx quartz serve`
7. Коммит и пуш

**Совет:** Используй существующие страницы как примеры!
