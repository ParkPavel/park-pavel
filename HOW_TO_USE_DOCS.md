## 🎯 Цель созданной документации

- При первом знакомстве с проектом

- Для обучения новых людей работе с проектом

**Как использовать:**
```

2. Дай ссылку агенту: "Прочитай AGENT_GUIDE.md для контекста"

```

## 🛡️ Принципы безопасной работы

При работе через агента **ВСЕГДА**:

1. ✅ Давай агенту ссылку на AGENT_GUIDE.md или AGENT_QUICK_REFERENCE.md
2. ✅ Проси показать git diff перед коммитом
3. ✅ Проверяй, что агент не трогает запрещённые файлы
4. ✅ Требуй тестирования через `npx quartz build`
5. ✅ Проверяй результат на GitHub Actions
6. ✅ Делай маленькие коммиты вместо больших
7. ✅ Используй понятные commit messages

**НИКОГДА**:

1. ❌ Не давай агенту полную свободу без контекста
2. ❌ Не коммить без просмотра git diff
3. ❌ Не трогай файлы из "запрещённого" списка
4. ❌ Не пропускай тестирование сборки
5. ❌ Не делай несколько не связанных задач в одном коммите

Эта документация будет развиваться вместе с проектом.

**Когда обновлять:**
- Добавлены новые кастомные компоненты

- Найдены новые best practices
- Обнаружены частые ошибки

**Как обновлять:**
```bash
# Открой нужный файл
vim AGENT_GUIDE.md

# Внеси изменения

# Коммит
git add AGENT_GUIDE.md
git commit -m "docs: обновлено руководство агента"
git push
```
