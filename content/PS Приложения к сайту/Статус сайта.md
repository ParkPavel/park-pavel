### Яндекс.Метрика

| Параметр | Значение |
|----------|----------|
| Статус | ⚠️ Не настроена |
| Поддержка в Quartz | ✅ Добавлена (`provider: "yandex-metrica"`) |

**Для подключения Яндекс.Метрики:**

1. Зарегистрируйте счётчик на [metrika.yandex.ru](https://metrika.yandex.ru/)
2. Скопируйте номер счётчика (например: `12345678`)
3. В файле `quartz.config.ts` замените настройку `analytics`:

```typescript
analytics: {
  provider: "yandex-metrica",
  counterId: "ВАШ_НОМЕР_СЧЁТЧИКА",
  clickmap: true,
  trackLinks: true,
  accurateTrackBounce: true,
  webvisor: true,   // запись сессий пользователей
},
```

> 💡 **Примечание:** Яндекс.Метрика особенно важна для российской аудитории — она даёт более точные данные по российским пользователям и предоставляет уникальные инструменты: Вебвизор, карту кликов, карту скроллинга.

## 🔌 Плагины Quartz

### Трансформеры
- **FrontMatter** — обработка метаданных
- **CreatedModifiedDate** — даты создания/изменения (из git и frontmatter)
- **SyntaxHighlighting** — подсветка кода (темы github-light/github-dark)
- **ObsidianFlavoredMarkdown** — поддержка синтаксиса Obsidian
- **GitHubFlavoredMarkdown** — GFM (таблицы, задачи и т.д.)
- **TableOfContents** — автоматическое оглавление
- **CrawlLinks** — обработка ссылок между страницами
- **Description** — автоматические описания
- **Latex** — математические формулы (KaTeX)

### Фильтры
- **RemoveDrafts** — скрытие черновиков

### Эмиттеры
- **AliasRedirects** — поддержка псевдонимов страниц
- **ComponentResources** — CSS/JS ресурсы компонентов
- **ContentPage** — генерация страниц контента
- **FolderPage** — страницы папок
- **TagPage** — страницы тегов
- **ContentIndex** — карта сайта и RSS
- **Assets** — статические ресурсы
- **Static** — статические файлы
- **NotFoundPage** — страница 404
- **CustomOgImages** — автогенерация OG-изображений
